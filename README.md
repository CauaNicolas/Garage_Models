## 💻 Sobre o Projeto

Este projeto criado para aplicar fundamentos de orientação a objetos, no qual consiste no desenvolvimento de um site de vendas de miniaturas de carros.

## 🛠️ Tecnologias Utilizadas

* **Python** (Versão 3.x ou superior)
* **Flask** (Framework Web micro)

## 🔧 Como Executar o Projeto

Siga os passos abaixo para rodar a aplicação na sua máquina local:

### 1. Clonar o repositório
```bash
git clone https://github.com/CauaNicolas/Garage_Models
```

### 2. Criar e ativar um ambiente virtual (Recomendado)
```bash
# No Windows:
python -m venv venv
.\venv\Scripts\activate

# No Linux/macOS:
python3 -m venv venv
source venv/bin/activate
```

### 3. Instalar o Flask
```bash
pip install flask
```

### 4. Rodar a aplicação
Você pode iniciar o servidor utilizando o comando oficial do Flask:
```bash
flask --app app run --debug
ou
python app.py

```

### 5. Acessar no navegador
Abra o seu navegador e acesse o endereço local gerado:
```text
(http://127.0.0.1:5000)
```
